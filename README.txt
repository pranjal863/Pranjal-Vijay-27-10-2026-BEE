# ShopEasy - E-Commerce Shopping Cart

A simple mini-project made using only:
- HTML
- CSS
- JavaScript

## Features

1. Product filtering and sorting
   - Search products
   - Filter by category
   - Sort by price or name

2. Shopping cart
   - Add products
   - Remove products
   - Increase/decrease quantity

3. Price calculation
   - Subtotal
   - Discount
   - Final total

4. Coupon
   - Use coupon: SAVE10
   - Gives 10% discount

5. Checkout UI
   - Name
   - Email
   - Address
   - Payment method
   - Place order button

## How to run

1. Extract the ZIP file.
2. Open `index.html` in Chrome/Edge.
3. The project runs directly in the browser.

No installation or backend is required.
